# onit para Android

Descarga la beta de onit desde [la primera versión publicada](https://github.com/FlyingKoala01/onit-apk-releases/releases/tag/v0.2.0-beta.1) o usa el [enlace directo a la APK](https://github.com/FlyingKoala01/onit-apk-releases/releases/download/v0.2.0-beta.1/onit.apk).

## Instalación

1. Descarga la APK desde el móvil Android.
2. Abre el archivo descargado y permite la instalación desde el navegador o gestor de archivos cuando Android lo solicite.
3. Abre onit e inicia sesión o crea una cuenta.

Esta es una **beta de prueba** (versión 0.2.0, identificador Android `com.cunde.app`) firmada con un certificado de depuración. Las próximas APK deberán usar la misma firma para actualizarla sin reinstalar. La distribución para Google Play necesitará una compilación de producción.
